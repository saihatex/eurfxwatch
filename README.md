# EUR/FX Market Surveillance & Execution Engine

Institutional quantitative surveillance and price action modeling engine for EUR/USD and cross-currency pairs.

## Architecture

- **Decision Engine**: High-probability trade decision state machine.
- **Price Action Engine**: Smart Money Concepts (SMC), market structure, and liquidity sweep detection.
- **Calibration & Validation**: Historical backtesting and statistical parameter tuning.
- **Research & Logs**: Automated execution and quant report generation.
